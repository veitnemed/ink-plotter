# Штриховой текст

Локальный прототип: русский текст → координаты штрихов → SVG для просмотра в браузере или импорта в программу для перьевого плоттера. Это не обычный шрифт: буквы состоят из осевых линий, и отдельные штрихи не соединяются между собой.

## Попробовать

Нужен Python **3.9+**. Установка пакетов и интернет не нужны. В Windows вместо `python` можно использовать `py`.

```sh
python plotter.py render --demo -o demo.svg
python plotter.py render --text "Привет, мир!" -o hello.svg
python plotter.py render --input text.txt --width 210 --height 297 --margin 12 --size 6 -o text.svg
```

Откройте `demo.svg` в браузере. Готовый [пример](demo.svg) лежит в репозитории. Бумага, размер букв и поля задаются в миллиметрах; по умолчанию лист A4. Строки переносятся автоматически. Если текст не помещается или в наборе нет нужного символа, программа сообщит об этом и не перезапишет SVG.

## Нарисовать личный набор букв

```sh
python plotter.py edit --glyphs my-glyphs.json
python plotter.py render --text "Мама, я дома!" --glyphs my-glyphs.json -o handwritten.svg
```

В окне редактора введите **одну** букву, нажмите «Открыть», нарисуйте её мышью или пером и нажмите «Сохранить». Отпустите кнопку между штрихами; точку задавайте коротким движением. Регистр важен: личная строчная «а» подменит только строчную «а». «Отменить» удаляет последний штрих, «Очистить» и «Сохранить» убирают личное начертание из набора. Для редактора нужен Tkinter, который обычно входит в установку Python для Windows; без него можно править JSON вручную и пользоваться экспортом.

В [образце JSON](personal-demo.json) хранится начертание строчной «а». Формат: объект `glyphs`, в нём ключ — символ, значение — список штрихов. Штрих — упорядоченный список из двух или более точек `[x, y]`; диапазон обеих координат от 0 до 10, начало в левом верхнем углу. Файл можно редактировать в любом текстовом редакторе и хранить только у себя.

```sh
python plotter.py render --text "Мама, я дома!" --glyphs personal-demo.json -o example.svg
python -m unittest -v
```

## Границы прототипа

- Встроенный набор — оригинальные геометрические начертания 33 русских букв (включая Ё), цифр и знаков `.,!?:-—`. Строчные без личного образца выглядят как прописные. Нет распознавания почерка по фото, автоматического обучения, соединений букв или имитации давления пера.
- SVG содержит отдельные незалитые пути, без внешних шрифтов. Размер задан в мм, но при импорте проверьте масштаб и рабочую область в программе конкретного плоттера. Порядок путей в SVG не гарантирует порядок выполнения в стороннем приложении.
- G-code, прямое управление станком и испытания на реальном оборудовании в эту версию не входят. Параметры подъёма пера, рабочая зона и ноль зависят от модели.
